# campus-wall 校园墙

## 板块

- 失物招领
- 二手交易
- 提问求助
- 吐槽

## 具体功能

- 不登录能看，登录才能发帖、评论、点赞、收藏、举报。
- 发帖可以选昵称或者匿名，匿名就只显示匿名用户。匿名只是不显示名字，后台还是能找到发帖人，用来处理违规；自己发的匿名帖，自己还是能改能删。
- 帖子发了直接能看到，不用等审核。管理员能删帖、删评论、处理举报、封号。发帖和评论有频率限制，违规内容靠举报和管理处理。
- 联系方式在“我的资料”里填好永久保存，发帖时自己选要不要公开，公开了别人才看得到。首页第一行按时间问候，顶栏有搜索框，搜完进搜索页再筛校区和板块；公告栏和首页、发帖平行，只有管理员能发公告，管理后台也只有管理员才看得到。
- 能传图片，失物和二手最好配图。

## 技术栈

- 前端：Vue 3 + Vite
- 后端：Java + Spring Boot
- 数据库：MySQL

## 目录

- backend：后端
- frontend：前端
- docs：数据库、接口、隐私安全、部署这些说明

## 本地跑起来

### 1. 数据库

```bash
docker compose up -d db
```

数据库名默认是 campus_wall，账号密码看 .env.example。

数据库默认不对外开端口，本地想用工具直连的话，用 docker-compose.dev.yml 那份，它只绑本机。

### 2. 后端

```bash
cd backend
mvn spring-boot:run
```

默认在 http://localhost:8080

### 3. 前端

```bash
cd frontend
npm install
npm run dev
```

默认在 http://localhost:5173，接口会代理到后端的 /api。

## 登录

用学号注册登录，注册填 11 位数字学号、昵称、校区和密保问题，登录成功拿到 JWT，后面发帖评论都要带上它。学号注册后就不能改了，昵称 30 天只能改一次，改密码要先输原密码，忘密码可以在登录页用学号加密保问题重置。

第一版没接学校系统核验，学号就是个登录账号。对外不显示学号，只显示一个随机公开 ID，管理后台也看不到学号，想看得填理由，还会留记录。注销之后学号会清掉，自己的帖子和评论会变成匿名。

密码和密保答案只存加密后的哈希，不存明文。注意：数据库是 ddl-auto: update，拉下来重启后端后 users 表会自动加上密保问题、密保答案和上次改昵称时间这三列。

## 开源和用户数据

代码公开，用户数据不公开，也不进仓库：

- 真实数据库连接、密钥、上传文件都放环境变量和本地配置，不写进代码。
- .env、本地配置、uploads 这些已经在 .gitignore 里了。
- 别把真实学号、密码、联系方式、数据库备份提交到 GitHub。
- 上线前记得换掉默认 JWT 密钥，具体看 docs/deployment.md。
